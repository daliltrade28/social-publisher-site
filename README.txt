Files:

- privacy.html (privacy policy)
- terms.html (terms of service)
- style.css (shared styling)

BEFORE TIKTOK APP REVIEW:
1. Replace the generic support contact paragraphs with a REAL, publicly accessible support email address you control.
2. Verify the privacy statements accurately describe the software you actually operate. Update the text if any behavior differs.
3. Upload these four files to a public GitHub repository with GitHub Pages enabled (Settings > Pages > Deploy from branch > main / root).
4. Wait for GitHub Pages to deploy. Your URLs will look like:
   https://YOUR_USERNAME.github.io/REPO_NAME/
   https://YOUR_USERNAME.github.io/REPO_NAME/privacy.html
   https://YOUR_USERNAME.github.io/REPO_NAME/terms.html
5. Use the homepage as the TikTok Web/Desktop URL, and the other two URLs for their matching fields.
6. The website alone does not guarantee TikTok app review approval or domain verification for photo URLs.
7. Never upload .env, API tokens, or secrets to the public repository.
